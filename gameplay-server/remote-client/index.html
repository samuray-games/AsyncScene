Ваш скрытый ход

Если отправка оборвётся, клиент временно сохранит этот ход и его номер в IndexedDB, чтобы повторить ту же команду после перезапуска. Bearer-токен при этом не сохраняется без отдельного согласия.

«Забыть это устройство» удаляет сохранённый ключ только из этого браузера. Это не отзывает ключ на сервере.
